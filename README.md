# $PLANETEARTH Token — there's only one

Guiding principles:

- The maximum supply is 1 $PLANETEARTH. There is no planet B after all.

## Compile and test

```shell
npx hardhat compile
npx hardhat test
```

## Deploying the contract

### Hardhat test network

```console
$ npx hardhat run scripts/deploy.js
```

### To a live network (e.g. Rinkeby)

See [Deploying to a live network](https://hardhat.org/tutorial/deploying-to-a-live-network.html).
